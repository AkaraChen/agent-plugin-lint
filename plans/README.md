## Direction

Not scheduled. These are options, not defects.

- **Skill issue source locations.** `SkillIssue.location` is always `None`. `DESIGN.md` says to fill a position only when the parser can prove it. A later change could record the frontmatter line from `parse_frontmatter`'s offsets. Do not guess columns.
- **Directory hardlinks in discovery.** `lint_path` dedups canonical paths, which collapses symlinks (tested in `s2b.rs`) but not directory hardlinks. Unprivileged macOS cannot create those. Worth doing only if a Linux test can create one and show two logical roots with the same identity escaping `DISCOVERY_AMBIGUOUS_ROOT`.

## Findings considered and rejected

- Non-ASCII skill names return before hyphen and directory checks (`validator.rs` `name`). Locked by `unicode_name_is_not_silently_normalized_or_rejected` and D6: do not reject on normalization differences, and do not silently NFKC. An ASCII-vs-fullwidth pair is a compatibility difference, not a certain mismatch.
- `RULE_NOT_EVALUATED` for rules that truly have no target-level row. `lib.rs` and `finish_report` document this. Strict must not promote it. 002 only adds rows where the scanner did observe the target.
- `AS-SIZE-GUIDANCE` stays `manual` even when the 500-line advisory fires. `scripts/review/skills.py` requires that status. One coverage row cannot also be the token-budget manual result.
- Bare command `..` matches the D5 conservative core `._+-` and is not a MUST. `DESIGN.md` §7 forbids inventing a tighter character whitelist.
- Diagnostic language. Code, tests, and `README.md` are English. `DESIGN.md` still says messages are Chinese, and `AGENTS.md` says Chinese diagnostics. `DECISIONS.md` does not pick a language. This goal forbids flipping language to reconcile that drift.
- Resource-walk depth cap. Not added. 400 nested directories completed; the next limit observed here was the OS path length, not a panic.
- `NOT_IMPLEMENTED_S2B`. Dead on the accepted path after `coverage.retain`. Deleting the string touches the manifest gate for no user-visible change.
- MSRV pin. `REVIEW.md` records Rust 1.97/1.98 passing and says that is not a minimum. Do not write `rust-version` without a version that was actually tested as the floor.
